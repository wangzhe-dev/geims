# 2048 微信小程序游戏

一个经典的2048益智游戏的微信小程序版本。

## 游戏简介

2048是一款数字拼图游戏，玩家通过滑动屏幕合并相同数字的方块，目标是创建出数值为2048的方块。

## 游戏规则

- 通过滑动屏幕（上、下、左、右）来移动方块
- 相同数字的方块碰撞时会合并成一个方块，数值为两者之和
- 每次移动后，会在随机空位生成一个新方块（90%概率是2，10%概率是4）
- 当达到2048时获胜
- 当棋盘填满且无法移动时游戏结束

## 功能特性

✅ 完整的2048游戏逻辑
✅ 触摸滑动控制
✅ 分数统计和最高分记录
✅ 精美的UI设计和动画效果
✅ 游戏状态管理（胜利/失败判断）
✅ 本地存储最高分

## 技术栈

- 微信小程序原生开发
- WXML + WXSS + JavaScript

## 快速开始

1. 安装微信开发者工具
2. 导入项目到微信开发者工具
3. 点击编译即可运行

## 如何游玩

1. 打开小程序后自动开始新游戏
2. 在游戏面板上滑动手指来移动方块
3. 合并相同数字的方块获得更高分
4. 点击"新游戏"按钮重新开始
